# Worker Status Wording

This is the final worker-facing wording set for visible mode and limitation states.

## English

- Online full guidance available:
  - `Online full mode`
  - `Full grounded guidance is available while the backend connection is working.`
- Offline quick emergency guidance only:
  - `Offline guarded mode`
  - `The app is using limited local emergency guidance because the backend is unavailable.`
- Offline backup not ready on this device:
  - `Cloud guidance is unavailable, and local emergency backup is not ready on this device.`
- Cloud unavailable, using local limited guidance:
  - `The app is using limited local emergency guidance because the backend is unavailable.`
- Local guidance is limited, get help now:
  - `This is limited local emergency guidance because the full cloud-grounded controller is unavailable.`

## Malay

- `Mod penuh dalam talian`
- `Panduan penuh berasaskan awan tersedia selagi sambungan backend berfungsi.`
- `Mod berjaga-jaga luar talian`
- `Aplikasi menggunakan panduan kecemasan setempat yang terhad kerana backend tidak tersedia.`
- `Panduan awan tidak tersedia, dan sandaran kecemasan setempat tidak sedia pada peranti ini.`
- `Ini ialah panduan kecemasan setempat yang terhad kerana pengawal penuh berasaskan awan tidak tersedia.`

## Bangla

- `অনলাইন পূর্ণ মোড`
- `ব্যাকএন্ড সংযোগ কাজ করলে পূর্ণ ক্লাউড-ভিত্তিক নির্দেশনা পাওয়া যাবে।`
- `অফলাইন সতর্ক মোড`
- `ব্যাকএন্ড না থাকায় অ্যাপ সীমিত লোকাল জরুরি নির্দেশনা ব্যবহার করছে।`
- `ক্লাউড নির্দেশনা পাওয়া যাচ্ছে না, আর এই ডিভাইসে লোকাল জরুরি বিকল্প প্রস্তুত নয়।`
- `পূর্ণ ক্লাউড-ভিত্তিক কন্ট্রোলার না থাকায় এটি সীমিত লোকাল জরুরি নির্দেশনা।`

## Bahasa Indonesia

- `Mode penuh online`
- `Panduan penuh berbasis cloud tersedia selama koneksi backend berjalan.`
- `Mode berjaga offline`
- `Aplikasi memakai panduan darurat lokal yang terbatas karena backend tidak tersedia.`
- `Panduan cloud tidak tersedia, dan cadangan darurat lokal belum siap di perangkat ini.`
- `Ini panduan darurat lokal yang terbatas karena controller penuh berbasis cloud tidak tersedia.`

## Wording Principles Applied

- short enough for field use
- clear about online vs offline
- does not pretend offline is full SDS guidance
- avoids overly technical language in the primary worker-facing banner
