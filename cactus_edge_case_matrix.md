**Cactus Edge Case Matrix**

`No network at startup`
- handled by startup health failure -> offline guarded mode
- local catalog remains available

`Network drops after chemical identification`
- local state already holds chemical and language
- submit can still take local guarded or limited preventive path

`Network drops before full response`
- route falls back to local guarded emergency or limited preventive response

`Local model unavailable`
- online cloud path still works
- offline capability is reduced and must stay labeled as limited

`Local model initialization failure`
- runtime stores `localModelError`
- cloud path still available when online

`Low-confidence local classification`
- local clarification path exists instead of unsafe forced completion

`QR success but cloud unreachable`
- identification still works locally
- emergency path can degrade to local guarded response

`Manual chemical selection while offline`
- supported from embedded local catalog

`Preventive query while offline`
- limited local defer-to-online response

`Ambiguous phrasing such as ear / face / near-eye`
- local canonicalization route exists before cloud handoff or offline guarded fallback

`Cloud timeout after route selection`
- product fallback remains local limited mode

`Stale local metadata`
- embedded catalog is narrow and static for demo chemicals only
- this is a bounded risk, not a dynamic SDS sync system
