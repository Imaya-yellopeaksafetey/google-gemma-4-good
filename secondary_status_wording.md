# Secondary Status Wording

These are the smaller secondary readiness/status labels intended for judges, operators, and technically curious users.

## English

- Section title: `System readiness`
- Backend:
  - `Connected`
  - `Unavailable`
- Local fallback:
  - `Ready on this device`
  - `Model import needed`
  - `Unavailable on this device`
- Active route:
  - `Cloud full guidance`
  - `Local guarded fallback`

## Malay

- Section title: `Status kesiapsiagaan`
- Backend:
  - `Bersambung`
  - `Tidak tersedia`
- Local fallback:
  - `Sedia pada peranti ini`
  - `Import model diperlukan`
  - `Tidak tersedia pada peranti ini`
- Active route:
  - `Panduan penuh awan`
  - `Sandaran berjaga-jaga setempat`

## Bangla

- Section title: `সিস্টেম প্রস্তুতি`
- Backend:
  - `সংযুক্ত`
  - `পাওয়া যাচ্ছে না`
- Local fallback:
  - `এই ডিভাইসে প্রস্তুত`
  - `মডেল ইমপোর্ট দরকার`
  - `এই ডিভাইসে পাওয়া যাচ্ছে না`
- Active route:
  - `ক্লাউড পূর্ণ নির্দেশনা`
  - `লোকাল সতর্ক বিকল্প`

## Bahasa Indonesia

- Section title: `Status kesiapan`
- Backend:
  - `Terhubung`
  - `Tidak tersedia`
- Local fallback:
  - `Siap di perangkat ini`
  - `Perlu impor model`
  - `Tidak tersedia di perangkat ini`
- Active route:
  - `Panduan penuh cloud`
  - `Cadangan berjaga lokal`

## Notes

- This wording is intentionally secondary, not primary worker guidance.
- It explains route/readiness state without exposing low-level implementation details.
- It is now intended to localize with the selected language rather than remain English-only.
